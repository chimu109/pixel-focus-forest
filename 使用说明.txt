专注森林 · iPad / iPhone 网页应用

一、上线（GitHub Pages，无需写代码）
1. 用 Safari 或电脑浏览器登录 https://github.com 并新建 public（公开）仓库，例如 pixel-focus-forest。
2. 打开仓库 → Add file → Upload files，将此目录内的 index.html、manifest.webmanifest、sw.js、三个 PNG 图标、icon.svg、.nojekyll 上传到仓库根目录。不要上传 ZIP 文件本身，否则网页不会解压运行。
3. 打开 Settings → Pages → Build and deployment → Deploy from a branch，选择 main、/(root)，点击 Save。
4. Pages 页面出现 Visit site / 网站地址后，复制该地址到 Safari 打开（常见结构为 https://用户名.github.io/pixel-focus-forest/）。发布可能需要几分钟。
5. iPad Safari：分享按钮 → 添加到主屏幕 → 打开为网页 App → 添加。iPhone 同理。

二、功能
倒计时 10 / 15 / 25 / 45 / 60 分钟；自由计时满10分钟可完成种树；暂停、放弃、任务记录、累计时长、最近30棵树、导出 CSV、JSON 备份/导入。

三、重要说明
- 同一网址在手机和平板上可访问，但本地专注记录不会跨设备自动同步。定期备份 JSON，换设备时手动导入。
- Safari 与主屏幕网页 App 的数据存储可能彼此独立。建议固定用一种方式，并导出备份后再切换。
- 页面在后台可能暂停 JavaScript 运行；重新打开时，倒计时会按真实经过的时间恢复；完全关闭且超时后，重进网站会结算。
- 网页不能可靠保证在锁屏/关闭后按时发出声音或系统通知，当前版本不提供后台提醒。
- 不要将备份 JSON 上传到公开 GitHub 仓库，备份记录可能包含学习任务等个人信息。

四、文件说明
index.html 是网站本体；sw.js 是离线缓存；manifest.webmanifest 和图标用于主屏幕安装；.nojekyll 保证 Pages 直接处理文件。
